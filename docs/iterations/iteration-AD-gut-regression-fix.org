** Root cause 1 — typed-ternary crash in =resolve_action_use_case.gd:640=

When a plain-Dictionary combatant (used by the old encounter.gd test path
and by simulator.gd) is killed in combat, =_finalize_strike_result()=
crashes with:

#+BEGIN_QUOTE
SCRIPT ERROR: Invalid access to property or key 'combatant_id' on a base
object of type 'Dictionary'.
  at: ResolveActionUseCase._finalize_strike_result
      (res://core/application/resolve_action_use_case.gd:640)
#+END_QUOTE

The guilty line (line 640) is:

#+BEGIN_SRC gdscript
var target_cid: String = target.get("combatant_id", "") if target is Dictionary else target.combatant_id
#+END_SRC

GDScript 4.3 evaluates *both* branches of a ternary when the left-hand
variable is typed (=: String=), so =target.combatant_id= (the =else=
branch) runs on a plain Dictionary before the runtime condition check can
suppress it.  The fix is a plain if/elif block:

#+BEGIN_SRC gdscript
var target_cid: String
if target is CombatantClass:
    target_cid = target.combatant_id
else:
    target_cid = target.get("combatant_id", "")
#+END_SRC

=CombatantClass= is already preloaded earlier in the same file (search
for =const CombatantClass= — it is used at line 602 for the EffectsApplier
branch).

This crash cascades into most of the other 10 failures: the script error
causes Godot to abort the action resolution mid-function, leaving the
encounter in an inconsistent state that triggers the safe-DRAW backstop,
produces zero =combatant_defeated= events, and corrupts the per-round
budget tracking for subsequent rounds.

** Root cause 2 — stale test expectation in =tests/test_round_events.gd=

Commit =6f902e1= (before sprint AC) added =combatant_id= to
=RoundEvents.CombatantDefeatedEvent.to_dict()=.  The test
=test_combatant_defeated_event_to_dict_matches_fields= in
=tests/test_round_events.gd= was written before that commit and does not
include =combatant_id= in its expected dictionary.  The fix is to add the
=combatant_id= key to the expected dict in the test.

Current failing assertion:

#+BEGIN_QUOTE
DICTIONARY({"round":4,"name":"Orc","defeated_by":"Lyra","combatant_id":""})
!= DICTIONARY({"round":4,"name":"Orc","defeated_by":"Lyra"}).
#+END_QUOTE

The test must expect ={"round": 4, "name": "Orc", "defeated_by": "Lyra",
"combatant_id": ""}=.

** AD-1  Fix typed-ternary crash in =_finalize_strike_result()=

*File:* =core/application/resolve_action_use_case.gd=

Replace lines 638–644 (the =target_defeated= / =target_cid= block) with the
safe if/elif form:

#+BEGIN_SRC gdscript
var target_defeated: bool = target.hp_current <= 0 if target is Dictionary else (target.hp_current <= 0)
if target_defeated:
    var target_cid: String
    if target is CombatantClass:
        target_cid = target.combatant_id
    else:
        target_cid = target.get("combatant_id", "")
    var defeated_event = RoundEventsClass.CombatantDefeatedEvent.new(
        round_number, target.name, combatant.name, target_cid
    )
    _emit_event(defeated_event)

dot-notation read of an existing key); only the ternary on line 640 is the
problem.  You may simplify the =target_defeated= line back to:
=var target_defeated: bool = target.hp_current <= 0=
if the existing line is not typed.
