#+TITLE: Iteration R — MainScene Decompose
#+PROPERTY: sprint 26
#+PROPERTY: version 0.3.0

* Overview

MainScene.gd has grown to 3,678 lines — a factor of ~2× its post-Iteration-K
size of 1,915 lines. Every new feature iteration has added logic directly into
MainScene because it was the convenient host. This iteration extracts that logic
into dedicated controllers so that MainScene returns to being a thin composition
root: it wires controllers together, routes signals, and nothing else.

Target: MainScene.gd ≤ 1,000 lines after all extractions. FEAT-009 is the
hard gate — if MainScene.gd exceeds 1,000 lines, the iteration is NOT complete.

* !! CRITICAL CONSTRAINT — MainScene is the composition root

  #+BEGIN_QUOTE
  MainScene.gd MUST NOT contain feature logic.
  It exists only to:
    1. Instantiate and configure dedicated controller objects
    2. Wire signals and callbacks between controllers
    3. Pass node/resource references to controllers on construction

  Every item in this iteration MOVES code OUT of MainScene into a
  dedicated controller file. Do not add new logic to MainScene.
  Do not leave shim duplicates in MainScene after extraction.
  #+END_QUOTE

This constraint applies to ALL future iteration briefs as well. Each feature
iteration brief must include this constraint in its own scope section.
