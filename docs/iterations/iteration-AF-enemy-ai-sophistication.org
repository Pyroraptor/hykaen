#+TITLE: Iteration AF — Enemy AI Sophistication: Tiered Planners + Multi-Action Turns
#+SPRINT: 45
#+VERSION: 0.2.6

* Goal

Give enemies genuine multi-action turns and tiered AI sophistication.
A basic skeleton stays simple (nearest target, Strike only), while a Grunt
may Step-then-Strike in the same turn, and a Soldier may open with a
Stride+Strike Combination, close with a ranged Step-to-safety, or zero in
on the party's caster.

All tiers share the same application-layer verb execution — the enemy
=CombineActionController.execute()= path is the SAME one the player uses.
No rule divergence.  Enemy-specific code is confined to *which actions to
plan* (tier logic), not *how actions execute*.

* Current state (verified 2026-08-15)

- =AIDecisionPort.decide_action(combatant, targets) -> Dictionary= returns
  exactly one action per call (={action_type, target}=).
- =_decide_ai_action()= in =round_session.gd= (line 2021) uses
  =Callable.get_argument_count()= reflection to dispatch 2-arg vs 4-arg
  decide_action() variants.
- =advance_ai_turn()= reads =ai_decision["action_type"]= and handles only
  ="Stride"= or =Strike= (melee) — no multi-action sequence, no Combine,
  no ranged verb.
- All enemies share the same AI class regardless of enemy type.
  =EnemyResource= has no =ai_tier= field.
- Targeting: nearest living party member.  Tie-breaks by lowest =(q,r)=.
- Stride-then-Strike is one decision split across two turns: decide_action()
  executes the Stride inside its own body, then returns a Strike decision.
  This is a legacy artifact (FEAT-004 doc comment) that becomes a clean
  two-item plan under the new architecture.
- GUT baseline: 3824 passing, 0 failing, exit 0.

* Non-goals

- *Tactician AI* (cover-driven repositioning, chokepoints, elevation) —
  deferred until cover/terrain systems exist.  =HexScorer= wires cover and
  terrain as zero-weighted hooks from day one; no logic behind them yet.
- *Weapon swap AI* (stow weapon + draw other) — bad action economy; talent
  compresses it later.  Ranged→melee fallback uses whatever the enemy
  already holds in =weapons[0]=.
- *Enemy spell AI* — no enemy mages in the prologue.  Spell-casting enemies
  are deferred; intellect-gated budget logic is already in domain.
- *Multi-hex enemy footprint* — tracked in
  =docs/refactors/multi-hex-enemies.org=; separate large refactor.
- *Per-player-weapon-choice reactions* — enemy reaction AI uses the same
  best-weapon auto-selection Phase 2 (EWA Phase 2) established.
- *New prologue encounter content* beyond wiring =skeleton.tres= to
  =ai_tier = "mindless"= and (optional) a new enemy =.tres= to
  =ai_tier = "grunt"=.

* Architecture

** AIPlannerPort

A NEW port interface (=core/application/ai_planner_port.gd=) parallel to
=AIDecisionPort=:

#+BEGIN_SRC gdscript
class_name AIPlannerPort
extends RefCounted

## plan_turn(combatant, world_context) -> Array
##   Returns an ordered list of action plan dicts, each carrying:
##     { action_type: String, target?, destination?, combined_queue? }
##   Empty array = no actions (WAITs the turn).
##   The caller (RoundSession._execute_ai_plan) iterates the list and
##   dispatches each item in order, stopping if action_economy is exhausted.
func plan_turn(_combatant, _world_context: Dictionary) -> Array:
    push_error("AIPlannerPort.plan_turn() is abstract")
    return []
#+END_SRC

Each action plan item has the shape:
| Key              | Type       | Meaning                                        |
|------------------+------------+------------------------------------------------|
| =action_type=    | String     | ="Strike"=, ="Step"=, ="Stride"=, ="Combine"=  |
| =target=         | Dictionary | Enemy target dict (Strike/Combine with target) |
| =destination=    | HexCoord   | Hex to move to (Step/Stride)                   |
| =combined_queue= | Array      | Combination verb IDs (Combine only)            |

** AIWorldContext

A Dictionary built by =RoundSession= immediately before =plan_turn()= is called:

#+BEGIN_SRC gdscript
{
    "party":          [<living party Combatant objects>],
    "enemies":        [<all enemy Combatant objects>],
    "action_economy": <ActionEconomy for this actor's turn>,
}
#+END_SRC

=plan_turn()= implementations use it for targeting, movement, and economy
checks — they never call into RoundSession directly.

** Tier registry

=core/combat/ai_tier_registry.gd= — a static mapping from tier string to
planner class.  Loaded lazily; one instance per planner class.

| Tier string   | Planner class    | Notes                                  |
|---------------+------------------+----------------------------------------|
| ="mindless"=  | =MindlessAI=     | Default; nearest target, Strike only   |
| ="grunt"=     | =GruntAI=        | Lowest-HP target, Step-before-Strike   |
| ="soldier"=   | =SoldierAI=      | Combine + ranged priority, caster lock |
| (unrecognized) | =MindlessAI=    | Defensive fallback                     |

** Backward compat adapter

=_decide_ai_action()= in =round_session.gd= gains a second code path: if
=_ai_decision_port= responds to =plan_turn= (duck-typed check), call
=plan_turn(combatant, world_context)= directly.  Otherwise fall back to the
existing 2/4-arg =decide_action()= reflection path and wrap the result in a
single-element Array.  This means ALL existing test doubles continue to work
unchanged.

** AISP-4  MindlessAI

*File:* =core/combat/mindless_ai.gd= (new)

Extends =AIPlannerPort=.  Formalizes the behavior =core/combat/ai.gd=
currently provides.

Algorithm:
1. Select nearest living party member from =world_context["party"]=.
   Tie-break: lowest =(q, r)= (same rule as legacy =ai.gd=).
2. If in melee reach → return =[{action_type: "Strike", target: target_dict}]=.
3. If out of reach:
   a. Get =get_stride_destinations()= from =core/rules/movement.gd=.
   b. Pick destination that minimises =HexMath.hex_distance()= to target
      (same tie-break).  Only Stride if distance is strictly reduced.
   c. Return =[{action_type: "Stride", destination: best_dest},
              {action_type: "Strike", target: target_dict}]=.
4. No target (all party dead) → =[]=.

Do NOT copy any logic from =ai.gd=.  Call =Movement.get_stride_destinations()=
directly for the legal-destination set.  The "Stride-then-Strike" plan items
are what =advance_ai_turn()= previously assembled across two turns; they now
return as a two-item plan in ONE turn.

*Test* (new =tests/unit/core/combat/test_mindless_ai.gd=):
- Target already adjacent → plan has exactly one =Strike= item.
- Target two hexes away → plan = =[Stride(best_dest), Strike(target)]=.
- No living targets → =[]=.
- Tie-break: two equidistant targets → selects lowest =(q, r)=.

** AISP-7  EnemyCombineResolver

*File:* =core/combat/enemy_combine_resolver.gd= (new)

Extends =RefCounted=.  Bridges the AI planning layer to
=CombineActionController.execute()= without introducing a parallel rule.

#+BEGIN_SRC gdscript
## resolve(queue, actor, world_context) -> Dictionary
##   Builds `accumulated` programmatically (auto-selecting targets /
##   destinations from world_context), then calls
##   CombineActionController.execute({queue, actor, context, accumulated}).
##   Returns the execute() result dict.
func resolve(queue: Array, actor, world_context: Dictionary) -> Dictionary:
    var accumulated: Dictionary = _build_accumulated(queue, actor, world_context)
    return _combine_controller.execute({
        "queue":       queue,
        "actor":       actor,
        "context":     world_context,
        "accumulated": accumulated,
    })
#+END_SRC

=_build_accumulated()= walks the =queue= array.  For each verb that needs a
target, it picks the same target =SoldierAI= would pick.  For each verb that
needs a destination hex, it picks from =get_stride_destinations()= or
=get_step_destinations()= (whichever the verb requires).  The resolver never
prompts the player; it resolves all choices in pure code.

=_combine_controller= is injected in =_init()= so tests can replace it with
a spy.

*Test* (new =tests/unit/core/combat/test_enemy_combine_resolver.gd=):
- Spy on =CombineActionController.execute()=.
- =resolve(["stride", "strike"], actor, ctx)= →  =execute()= called once
  with a =payload= that has =queue= + =accumulated= keys.
- =accumulated= contains a =destination= for the =stride= verb and a
  =target= for the =strike= verb.
- Returns whatever =execute()= returned (pass-through check).

** AISP-8  SoldierAI

*File:* =core/combat/soldier_ai.gd= (new)

Extends =AIPlannerPort=.

Targeting:
1. *Caster priority*: if any party member has =mage_recharge_budget_remaining > 0=
   AND is alive, that combatant is the preferred target (tie: lowest HP).
2. Else: lowest =hp_current= living party member (same as GruntAI).

Turn planning (in priority order; stops when =action_economy= is exhausted):

*** Branch A — ranged engagement

Conditions: acting combatant carries =weapons[0]= with =range_hexes > 1=
AND target is not within OS-trigger range of any enemy (i.e. moving won't
draw an Opportunistic Strike).

1. Find a "safe hex": a hex within =weapons[0].range_hexes= of the chosen
   target that is NOT adjacent to any living enemy AND reachable by a Step
   or Stride.
2. If a safe hex exists:
   - Step/Stride to it (same Step-vs-Stride logic as GruntAI).
   - Ranged Strike at target.
   - Plan: =[{action_type: "Step"/"Stride", destination: safe_hex},
             {action_type: "Strike", target: target_dict}]=.
3. If no safe hex → fall through to Branch B (melee).

*** Branch B — Combine (Stride + Strike)

Conditions: =EnemyCombineResolver= is available AND =combatant.stamina > 0=
(the authored pool from AISP-1b — a Soldier with =stamina_max = 0= authored
on its =.tres= never enters this branch).

Use =EnemyCombineResolver.resolve(["stride", "strike"], actor, ctx)=.
Plan item: =[{action_type: "Combine", combined_queue: ["stride", "strike"],
              target: target_dict}]=.  The resolver handles execution.

*** Branch C — plain melee fallback

If neither Branch A nor B applies, falls back to GruntAI's plan
(Step/Stride + Strike).

*Test* (new =tests/unit/core/combat/test_soldier_ai.gd=):
- Caster (=mage_recharge_budget_remaining > 0=) prioritized over a nearer
  non-caster.
- Ranged safe hex found → Branch A plan =[Step, Strike]=.
- No safe hex, combine available → Branch B plan =[Combine]=.
- Neither A nor B → Branch C plan matches GruntAI output.

*** AISP-9-2  _execute_ai_plan(plan, combatant, action_economy)

New private helper.  Iterates the plan Array and dispatches each item:

#+BEGIN_SRC gdscript
func _execute_ai_plan(plan: Array, combatant, action_economy) -> Dictionary:
    var any_action_taken: bool = false
    for item in plan:
        var action_type: String = item.get("action_type", "")
        match action_type:
            "Stride":
                # Move the token (same logic as current advance_ai_turn's Stride branch)
                any_action_taken = true
                _reposition_token_after_ai_stride(combatant, item)
            "Step":
                # Free movement; no action economy spend (movement trait)
                Movement.step(combatant, item["destination"], _all_combatants())
                any_action_taken = true
                _reposition_token_after_ai_stride(combatant, item)
            "Strike":
                # Existing Strike resolution (reaction window, two-phase-commit,
                # resolve_action_use_case) — lift verbatim from advance_ai_turn body.
                if not action_economy.can_spend_action():
                    break
                # ... existing Strike resolution ...
                any_action_taken = true
            "Combine":
                # Delegate to EnemyCombineResolver; advance_ai_turn wires it in.
                var result = await _enemy_combine_resolver.resolve(
                    item.get("combined_queue", []),
                    combatant,
                    _build_ai_world_context(combatant, action_economy)
                )
                any_action_taken = any_action_taken or result.get("ok", false)
    return {"ok": true, "any_action_taken": any_action_taken}
#+END_SRC

=advance_ai_turn()= is refactored to call =_decide_ai_action()= (which now
returns an Array) and immediately pass the result to =_execute_ai_plan()=.
The existing =any_action_taken= logic and the =WAIT= path after it remain
in =advance_ai_turn()=.

*Important*: the two-phase-commit Strike block (pre-hit avoidance + on-hit
mitigation reaction windows) is a direct cut-paste from the current
=advance_ai_turn()= Strike branch into the ="Strike"= case of
=_execute_ai_plan()=.  Do NOT simplify or refactor it — it is exercised by
existing GUT tests that will break if the shape changes.
